## <a id="about"></a> 📋 About

Personal portfolio of **Nicola Amoruso**, Full Stack Web Developer based in Valencia, Venezuela, focused on **Backend and Artificial Intelligence**.

It showcases professional experience (LegalTec, Amoruso Inversiones, Show Proba), a full technology stack, and a contact section — with a highly interactive UI: smooth scrolling, physics-based micro-interactions, dark/light themes, and bilingual support (Spanish / English).

Built on an open-source Awwwards-inspired template, customized with real projects, profile content, and production-oriented stack details (RAG, LLMs, Redis, Google Cloud, and more).

## <a id="features"></a> ✨ Features

- **Advanced Animations**: Fluid transitions and micro-interactions with Framer Motion.
- **Physics-Based Components**: Dynamic UI elements (e.g. hanging profile) that respond to mouse movement.
- **Smooth Scroll**: High-quality scrolling experience with Lenis.
- **Dynamic Theme Support**: Dark and light mode with next-themes.
- **Bilingual**: Spanish and English via route-based i18n (`/es`, `/en`).
- **Responsive Design**: Mobile-first interface across devices.
- **Content-Driven**: Profile, projects, roadmap, and stack loaded from JSON for easy updates.

## <a id="technologies"></a> 🛠️ Technologies

- **Next.js 16**: App Router, SSR, and performance optimization.
- **React 19** & **TypeScript**: Typed UI and clean architecture.
- **Tailwind CSS 4**: Utility-first styling.
- **Framer Motion**: Animations, transitions, and gesture interactions.
- **Shadcn/UI** & **Radix UI**: Accessible, customizable components.
- **Lucide React**: Consistent icon set.
- **Lenis**: Smooth native-feeling scroll.
- **next-themes**: Theme switching.

## <a id="installation"></a> 🚀 Installation

Follow the steps below to run the project locally:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/namoruso/portfolio_web.git
   cd portfolio_web
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser. The default locale redirects to Spanish (`/es`).

### Useful scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Development server       |
| `npm run build` | Production build         |
| `npm run start` | Serve production build   |
| `npm run lint`  | Run ESLint               |

### Content

Editable content lives under:

- `contents/en.json` / `contents/es.json` — about, projects, roadmap
- `contents/shared.json` — contact, social links, tech stack
- `dictionaries/en.json` / `dictionaries/es.json` — UI copy
