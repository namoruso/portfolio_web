# Nicola Amoruso — Portfolio

Personal portfolio of **Nicola Amoruso**, Full Stack Web Developer based in Valencia, Venezuela, focused on **Backend and Artificial Intelligence**.

Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion. Bilingual (Spanish / English).

## Features

- Smooth scroll (Lenis) and Framer Motion animations
- Dark / light theme
- Spanish and English (`/es`, `/en`)
- Content driven by JSON (`contents/`, `dictionaries/`)

## Stack

- Next.js 16 · React 19 · TypeScript
- Tailwind CSS 4 · Framer Motion · Lenis
- Shadcn/UI · next-themes

## Getting started

```bash
git clone https://github.com/namoruso/portfolio_web.git
cd portfolio_web
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Default locale redirects to `/es`.

| Command       | Description            |
| ------------- | ---------------------- |
| `pnpm dev`    | Development server     |
| `pnpm build`  | Production build       |
| `pnpm start`  | Serve production build |
| `pnpm lint`   | Run ESLint             |

## Content

- `contents/en.json` / `contents/es.json` — about, projects, roadmap
- `contents/shared.json` — contact, social, tech stack
- `dictionaries/en.json` / `dictionaries/es.json` — UI copy
